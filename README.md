# Citizen Science Task Bounties
A decentralized platform for citizen science contributions and rewards.

## 🚀 Features

- Create scientific observation tasks
- Submit experimental data
- Earn tokens for verified contributions
- Automated reward distribution
- Secure verification system

## 🛠️ Technical Stack

- Clarity Smart Contracts
- Stacks Blockchain
- React Frontend
- Clarinet Testing Framework

## 📋 Getting Started

1. Install Clarinet
```bash
curl -L https://github.com/hirosystems/clarinet/releases/download/v1.0.0/clarinet-linux-x64.tar.gz | tar xz
```

2. Initialize project
```bash
clarinet new citizen-science-bounties
```

3. Run tests
```bash
clarinet test
```
